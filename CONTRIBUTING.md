
# Contributing to Linux Cheatsheet

Thank you for contributing to this project!

Please follow these rules before submitting your changes.

## 1. Branch Naming

Use this format for documentation branches:

`docs/<topic>`

Examples:

- `docs/grep`
- `docs/find`
- `docs/chmod`

## 2. Commit Messages

Use Conventional Commits.

For documentation changes, use the `docs:` prefix.

Examples:

- `docs: add grep examples`
- `docs: add find command guide`
- `docs: improve chmod examples`

## 3. Signed-off Commits

Every commit must include a sign-off.

Use:

`git commit -s -m "docs: add grep examples"`

The sign-off adds a line identifying the person making the contribution.

## 4. Documentation Requirements

Every command page must contain:

1. A clear title.
2. A one-line description.
3. At least five examples.
4. Expected output for every example.

## 5. Pull Requests

- Submit changes through a Pull Request.
- Explain what you changed.
- Link the related issue.
- Respond to review comments.
- Make requested corrections before merging.

Thank you for helping improve Linux Cheatsheet!
