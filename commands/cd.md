
# cd — Change Directory

The `cd` command changes your current working directory in Linux.

## Examples

### 1. Enter a directory

```bash
cd Documents
```

Output:
```text
You are now inside Documents.
```

### 2. Go to your home directory

```bash
cd ~
```

Output:
```text
/home/ops
```

### 3. Go to the parent directory

```bash
cd ..
```

Output:
```text
You move one directory level up.
```

### 4. Go to the root directory

```bash
cd /
```

Output:
```text
/
```

### 5. Return to the previous directory

```bash
cd -
```

Output:
```text
/home/ops/Documents
```
